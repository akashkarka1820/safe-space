█ Text Architectures (NLP)

XGBOOST

Powerful tree-based boosting algorithm. Yields high F1 scores by aggregating hundreds of decision trees voting on term-frequency matrices, effectively overpowering bias and preventing systemic overfitting during heavy comment loads.

LOGISTIC REGRESSION

Extremely fast and interpretable model for real-time text inference. Casts linear boundaries to separate offensive terms robustly given our TF-IDF embedding constraints.

SUPPORT VECTOR MACHINE (SVM)

SVM models cast strict hyperplanes in high-dimensional space to isolate toxic semantics. They provide blazing-fast, sub-millisecond inference speeds on edge devices with minimal system topology overhead.

STOCHASTIC GRADIENT DESCENT (SGD)

An efficient iterative optimization mechanism that updates parameters incrementally. Highly versatile and scalable for massive volumes of text detection without exhausting memory caches.

█ Vision Architectures (CNN)

MOBILENETV2

A lightweight network optimizing localized depthwise separable convolutions. Strategically deployed for immediate inference on uploaded memes without causing blocking logic or stalling server event loops—ideal for preliminary gateways.

RESNET50

An immense 50-layer framework maintaining systemic stability via Residual "skip-connections" that pass image gradients deeper into the network, completely mitigating vanishing gradients. Operates as our highly-accurate heavy architecture.
